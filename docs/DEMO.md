# Portfolio demo and resume notes

1. Start Ollama and FixLab. Verify the AI readiness indicator.
2. Build the Docker runner and verify test-runner readiness.
3. Load the average([]) example and explain the expected behavior.
4. Generate an analysis, inspect the diff and regression tests.
5. Run both versions; show the original failure and fixed pass.
6. Explain the statement-line coverage metric and its limits.
7. Edit a test, save the revision, and show that old results are cleared.
8. Re-run, accept/reject the patch, and export the session.

“Built a local AI-assisted Python debugging platform using Ollama, SQLite, and Docker, with reviewable patches, generated regression tests, isolated original-versus-fixed execution, and statement-line coverage reports.”

Do not add percentages, speedup claims, user counts, or accuracy claims without measurements. The project does not currently integrate GitHub repositories or deploy publicly.
